This is the GitHub Repository for the JSY01 project of CSCI 4970 (Capstone Project), in the semester of Autumn 2026.

The list of tasks:
<ul>
  <li>Add Request behavior</li><ul>
    <li>The “Add Request” button should open a pane where a request is allowed to be input</li>
  </ul>
  <li>Undo button</li><ul>
    <li>An Undo Button will allow undoing the most recent action</li>
  </ul>
  <li>Add Tag Request button</li><ul>
    <li>The “Add Tag Request” button should be investigated and debugged</li>
  </ul>
  <li>Edit Mode login improvements</li><ul>
    <li>The current Edit Mode should notify the user about Caps Lock</li>
    <li>If the login fails, a popup should explain why.</li>
  </ul>
  <li>Main search bar</li><ul>
    <li>The main search bar should be able to be double-clicked to clear it</li>
  </ul>
  <li>Historical customer and title data</li><ul>
    <li>The application should begin preserving historical request data.</li>
    <li>For each customer, we should retain:</li><ul>
      <li>Previous title requests</li>
      <li>The date of each request</li>
    </ul>
    <li>For each title, we should retain:</li><ul>
      <li>Previous customers who requested it</li>
      <li>The date of those requests</li>
      <li>The number of times the title has been requested</li>
    </ul>
  </ul>
  <li>Flag toggle in View Mode</li><ul>
    <li>The Flag toggle should be disabled while the application is in View Mode</li>
  </ul>
  <li>New Customer fields</li><ul>
    <li>Two new fields need to be added to the Customer data:</li><ul>
      <li>Creation Date: automatically populated whenever a new customer is created.</li>
      <li>Last Flagged Date: stores the most recent date that customer was flagged.</li>
    </ul>
  </ul>
</ul>
